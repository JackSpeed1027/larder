## 6. 环境事实与已知坑（踩过的，别再踩）

1. **Docker Hub 直连被墙**：Docker Desktop 要配 manual proxy（当时是 `127.0.0.1:7890`）；配置备份 `settings-store.json.bak-v01t02`。Docker Desktop 不会开机自启。
2. **MySQL my.cnf 在 Windows bind mount 下是 0777**，MySQL 会忽略并告警；字符集/时区走 compose command 参数，`infra/mysql/my.cnf` 只给 Linux 部署用。
3. **PowerShell 5.1 读无 BOM 的 .ps1 会当 ANSI**，中文注释破坏语法；`scripts/**.ps1` 必须是 UTF-8 with BOM。
4. **Boot 4 的 `@WebMvcTest`** 在 `org.springframework.boot.webmvc.test.autoconfigure`，需要 `spring-boot-starter-webmvc-test`。
5. **启动类别写 `@MapperScan`**：它会让 `@WebMvcTest` 切片也创建 mapper（无 sqlSessionFactory 直接失败）；Mapper 接口上的 `@Mapper` 足够。
6. **幂等键事务**：`idempotency_request` 插入必须 `REQUIRES_NEW`；owner 创建也必须 `REQUIRES_NEW` 先提交，否则外键校验等主事务未提交的 owner 行 → 504。
7. **并发去重回读**：`ingest` 用 `READ_COMMITTED`，否则唯一键冲突后回读看不到赢家 → 误 500。
8. **Maven wrapper** 的 `distributionUrl` 曾被生成成不存在的 `apache-maven-3-bin.zip`，已修为 3.9.11。
9. **pnpm/Node 不读 HTTPS_PROXY**（Node 24 需 `NODE_USE_ENV_PROXY=1`）；代理没开时直连 Maven/npm 反而可用，GitHub 需要代理。
10. `scripts/accept.py` 的 secrets 扫描会跳过 `reports/` 与 `docs/`（外部快照/规格含示例 key）。

## 7. 数据模型要点（V02-T01 已落地）

- `owner` → `item` → `content_revision`（不可变正文，目前 0 行）/ `job`（任务）→ `outbox`（待投递）
- `item`：`(owner_id, url_hash)` 唯一（URL 去重）；`current_revision_id` 正文指针（现为 NULL）；`active_generation_id` 索引发布指针（V04）
- `job`：`kind`（INGEST/ENRICH/INDEX/ASSIST/EMBED/EXPORT）、`state`（QUEUED/RUNNING/RETRY_WAIT/NEEDS_DECISION/SUCCEEDED/FAILED/CANCELLED/SUPERSEDED）、`lease_token`（fencing）、`processing_epoch`（作废旧结果）
- `outbox`：与业务同事务写 `PENDING`，V03 才写 Relay 投递
- `idempotency_request`：`(owner,route,key)` 主键 + `body_hash` + 响应快照；同 key 同 body 重放、不同 body 409
- `artifact`（V3）：已校验对象元数据，key=内容 sha256；`revision_artifact`（V3）：正文版本与对象的有序绑定（V02-T03 写入）
- `artifact`（V3）：已校验对象元数据，key=内容 sha256；`revision_artifact`（V3）：正文版本与对象的有序绑定（V02-T03 写入）

## 10. 名词速查

| 名词 | 一句话 |
|---|---|
| job | 持久化“工单”：对哪条内容做什么（kind）、做到哪一步（state） |
| kind | 任务类型枚举，契约里登记（不是运行时注册中心） |
| state | 状态机状态，只能按契约转移；终态不可逆 |
| lease | 限时领取（lease_owner/token/until），过期可被接管 |
| fencing token | 每次领取 +1；旧持有者迟到提交会被条件更新拒绝 |
| processing_epoch | 用户重抓时的代次，旧结果即使租约有效也不得发布 |
| outbox | 与业务同事务写下的待投递事件，Relay 负责发 MQ（至少一次） |
| inbox | 消费端去重表（V03） |
| idempotency key | 客户端命令去重键，配 body_hash + 响应快照 |
| 至少一次 | 消息可能重复，消费端必须幂等 |
