# Larder 拾藏 · Agent开发执行包

版本：agent-playbook-v3，2026-11-05建立，2026-11-06完成整理。**这是完整实施规格与派工包，不是已经实现的产品或实测履历。** 原始桌面压缩包、工作区SPEC及此前交付全部保留。本版承接完整工程目标，新增多窗口协作、前端强约束、表设计、代码封装、注释及递进门禁。

## 1. 给Agent的入口

协调窗口先读 [AGENTS](../AGENTS.md)、[11 四轮十二版本与并行DAG](11-四轮十二版本与并行DAG.md)、[12 多窗口协作与集成协议](12-多窗口协作与集成协议.md)，使用 [13 标准Prompt全集](13-Agent标准Prompt全集.md) 的协调启动Prompt。

实现窗口收到具体派工单后读取 `prompts/tasks/<任务ID>.md`；前端另读取 `prompts/frontend/<页面ID>.md`。不能只发一句“把整个项目做完”让各窗口自行解释边界。

在项目根目录（`D:\Work\Project\larder`）可运行：

```powershell
python scripts/validate_handoff.py
python scripts/validate_execution.py
python scripts/plan_dispatch.py --batch V01-T01
python scripts/build_task_prompts.py --check
```

这些只验证设计包、DAG和派工规则，不代表应用测试。缺少MySQL8.4/Docker/模型环境时不伪造业务结果。应用工程、真实迁移与测试入口由V01开始实施。

## 2. 最终做成什么

自托管的个人内容与学习工作台：收录网页、粘贴、PDF、视频链接及合法字幕/音频；版本化阅读、关键词与语义检索、集合标签笔记；可恢复的工具Agent、人工审批、显式长期记忆与安全压缩；四卡型复习、翻卡、备份恢复和可复现评测。

关闭AI后基础内容库与手动学习仍可用；浏览器脱网不保证服务器写入成功。最终简历为**一个项目、Java后端与Python Agent两块**，参考简历只作深度参照，不复制其成绩。

固定技术方向：Java21 / Spring Boot3.5 / Security / MyBatis-Plus / MySQL8.4 / Redis / RabbitMQ / Meilisearch / MinIO-S3 / Flyway / Testcontainers；Python3.12 / FastAPI / HTTP-SSE / JSONL；React19 / Vite / TS / Tailwind4 / shadcn / TanStack Query。精确补丁和兼容性在V01核验冻结；不自动升Boot4。八服务保留，Java模块化单体+独立Runner，不拆无必要微服务。

## 3. 交付组成

- **4轮，每轮3版本，共12版本；48个核心包+8项深入实验。** 同轮按真实依赖并行，上一轮放行后再进入下一轮。
- **72张独立Agent任务Prompt**：56张核心/实验工作包卡，16张前端页面/骨架子任务卡。前端任务属于核心包，不重复计工时。
- **20份专题规范**，覆盖产品、架构、数据、协作、前端、运维、代码、注释与面试证据。
- **43张表、380个字段的DDL设计**，表/字段均有COMMENT，配事务、索引、约束、迁移与验收说明；尚未在真实MySQL8.4执行。
- **16页合同、4张原创线框、可交互翻卡示范、4个官方截图链接**，配tokens和视觉验收，设计稿不冒充真实产品截图。
- JSON/OpenAPI起始契约、只读派工检查器、文档/依赖/SQL静态校验和交付hash清单。

## 6. 规格优先级与实施节奏

用户最新要求优先；AGENTS管理授权/保护；04+机器schema管理协议，18补充Java公开响应封装；16+DDL管理表设计；02/03管理机制；14/15+design管理前端；11+tasks管理派工；12管理协作；19管理递进边界；20管理注释。发现冲突先修成一致，再冻结新rev，不能选择最省事的一份。

核心产品估算328h+52h缓冲约380h，8项实验另40–80h，完整约420–460h、初估20–22周（视每周20–25h投入与学习返工调整）。窗口增加只能并行独立工作，不能跳过关键依赖和理解过程。

## 7. 不做什么

不自动开多个写窗口、不共享可写checkout、不清理用户原件/历史、不自动commit/push/发布；不静默删除MQ/MySQL/记忆等核心能力；不把静态稿/Mock/设计校验当真实产品；不编造面试指标。后续Agent从V01开始，按每轮门禁逐步实现与优化。
