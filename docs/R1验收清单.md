## 4. 手工验收路径（建议顺序）

1. **登录**：5173 → 错误密码应显示错误态，不应跳空白页；正确密码进资料库。
2. **收录**：保存 `https://example.com/?manual=1` → 返回后任务中心能看到 job，状态从 QUEUED→RUNNING→SUCCEEDED。
3. **阅读**：条目进入阅读页，正文为 example.com 抽取结果（约 156 字符），显示 revision 与 sha 前缀。
4. **笔记**：写一条笔记 → 刷新后仍在；空正文应 400 提示。
5. **标签/集合**：新建标签、同名再建（应复用同一 id）；新建集合后列表可见。
6. **重复收录**：同 URL 不同 key 返回 200 同一 item；同 key 不同 body 返回 409 `IDEMPOTENCY_PAYLOAD_MISMATCH`。
7. **取消**：任务 RUNNING 时取消 → `cancelRequestedAt` 有值；再回传结果 → 409 `CANCELLED_CONFLICT`。
8. **SSE**：`curl -N -b cookies http://127.0.0.1:8080/api/jobs/<jobId>/events` 首帧是 `snapshot`；带 `Last-Event-ID: 0` 重连仍能拿到 snapshot。
9. **任务中心轮询**：把浏览器切到后台再回来，列表应立即刷新（隐藏页 60s、回前台立即刷新）。
