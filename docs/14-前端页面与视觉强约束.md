执行对象：前端Agent、设计审查Agent、契约协调Agent。`design/tokens.json`、`design/page-contracts.json`、本文件以及本地reference-board共同构成designRev。它们约束实际应用，不是建议素材。遇到冲突由协调者修订并统一hash；worker不得选择自己喜欢的一版。

## 2. 产品视觉方向及禁用项

个人知识资料工作台，强调内容密度、长文阅读、可追溯的AI操作。默认浅色中性底、单一蓝色强调、低阴影、清楚的分隔线；暗色使用完整语义token。用户进入后首先看到资料库和“保存内容”，不是营销首页或十张统计卡。

必须遵守：统一Lucide图标（精确包版本由V01锁定）、系统字体栈、8px主节奏（允许4px辅助）、统一圆角。禁止同页面同时出现三套按钮形状、随机彩色分类卡、大面积渐变/玻璃背景、装饰性发光、emoji充当系统状态、跨页更换导航位置、远程字体CDN。图标按钮必须有可访问名称，提示不能只靠hover。

### 2.2 响应式规则

基准截图1440×900；辅助1280×800、768×1024、390×844。>=1280显示216侧栏；768–1279折叠为64px图标rail，图标标签可展开；<768侧栏变drawer、顶部菜单入口，主内容不产生横向滚动。<1280阅读证据栏默认关闭、打开为360px drawer（手机宽度100%）；>=1280为320px右栏。目录在<1440默认收起，不能让正文因三栏变成300px。

正文区先保障最小可读宽度；代码块/数据表仅内部横滚。手机将筛选区折成“筛选”按钮+已选chips；桌面表格变逐条列表，不隐藏标题/状态/主要操作。审批diff可内部横滚并提供换行开关。使用CSS断点，不用JS只在首次mount读取window宽度。

## 3. 应用骨架 F00

路由框架：顶部品牌“Larder 拾藏”，侧栏固定顺序“资料库 / 搜索 / Agent / 学习 / 任务”，下面分组“集合 / 标签”，底部“回收站 / 设置”。资料库是登录后默认页。主要保存按钮在顶栏右侧，所有主页面位置一致；阅读沉浸页可收起应用侧栏，但保留返回来源页及保存入口。

页面header包括标题、可选描述、操作组；主操作最多1个实心按钮，其余outline/ghost。全局Cmd/Ctrl+K打开命令/搜索入口，输入法组合态不触发；键盘快捷键在输入区域不劫持。面包屑/返回恢复筛选、页码和滚动位置。未知路由显示可返回的404；登录失效显示会话过期且保留可安全恢复的本地草稿，不无限跳转。

共享组件由F00 owner维护：AppShell、PageHeader、Button、Input、Dialog、Drawer、Tabs、Tooltip、Badge、StatusBadge、EmptyState、ErrorState、Skeleton、Pagination、ConfirmAction、CitationLink、AsyncStatus、Toast、FormField。不得每个页面再造一份相同按钮/错误态。shadcn生成组件也是受控源码，不能每个worker重新初始化覆盖。

## 4. 页面合同

### F01 资料库 `/library`

桌面从上到下：页面标题/总条目数（仅服务端已知值）；筛选工具条；内容列表；分页。默认每页20、可选10/20/50，与04和09的最大50一致。排序默认最近保存；选项最近更新、标题；状态/类型/标签/集合筛选同步URL。列表行最小88px：左侧40px类型图标/可选缩略图，中间标题最多2行、来源+时间一行、标签一行；右侧状态badge和更多按钮。没有封面不放破图或随机渐变。

点击标题进入保存版本阅读，来源域名单独打开原站（标外部链接）；整行不能变成套着按钮的无语义div。勾选进入批量栏，只对明确选择项操作，换筛选清选择并提示；“全选”仅当前页，跨页全选不得暗中扩大范围。批量移入回收站显示数量和撤销可用条件，Java最终校验权限和版本。

loading显示6行结构骨架，不先闪“暂无内容”；空库文案“保存第一篇内容”，提供链接/粘贴/文件入口；无筛选结果显示“没有匹配内容 / 清除筛选”；error保留筛选并给重试；processing/failed不能展示伪造摘要；旧内容更新中仍可阅读旧revision并注明。

### F02 保存内容 Dialog

由全局“保存内容”打开，桌面宽640px/max90vw，手机全屏。Tab固定“链接 / 粘贴文本 / 上传文件”。链接包含URL、可选标题、集合/标签；粘贴包含标题、文本（展示字数而非token承诺）；上传显示允许格式与服务端限制、进度、可取消；视频仅接受链接/合法字幕或合法音频输入，不提供下载绕过入口。

提交中按钮禁用但不清输入；同次提交复用idempotencyKey，失败可重试不重复创建；成功显示条目链接与任务状态，并失效资料库查询。保存成功不等于解析完成。失败分字段校验、网络未确认、服务拒绝；未确认时先查幂等结果，不盲目重发。关闭有未保存草稿时给保留/放弃选择；不记录正文到分析日志。

### F03 阅读器 `/items/:itemId?revisionId=...&chunkId=...`

1440屏幕参考：应用侧栏可折叠；正文区域居中max720px，顶部标题/来源/保存时间/版本提示；右侧证据320px。目录200px可展开，空间不够时drawer。顶部工具固定：返回、阅读设置Aa、笔记、AI辅助、更多。正文永远是主体，不用聊天框替代。

从搜索/citation进入时固定revisionId/chunkId，不能偷偷换最新文本。若存在更新版，横幅“正在查看检索时的版本 / 查看最新版本”；切版本明确改变URL。不存在引用定位显示“该片段暂不可定位”，可读原版本且不假高亮。

选中文本浮动操作“记笔记 / 解释 / 制卡”，取消选区时关闭；浮层不遮住选区、不靠拖动才能操作；高亮和笔记绑定revision+anchor。右栏Tabs“笔记 / AI / 信息”；AI结果区有来源引用、生成时间、重新生成、取消/预算错误。Markdown经过统一安全渲染，外部原文脚本不可执行。长文滚动稳定，回到页面恢复位置。旧revision/source缺失时给明确状态，不悄悄删笔记。

### F04 任务中心 `/jobs` 与任务 Drawer

列表字段：内容标题、阶段、状态、更新时间、操作。筛选运行中/需处理/失败/全部。Drawer显示人类可理解的阶段时间线、已发生事件、错误原因、重试/取消；traceId等诊断信息收进“诊断详情”。禁止显示假百分比；仅有阶段时用步骤和不确定进度条。

SSE按eventId去重；断流展示“连接中，状态可能延迟”，GET snapshot后再接续，不因重复事件产生第二条任务。取消显示“正在取消”直到服务器终态。NEEDS_DECISION用“需要确认下一步”，说明调用结果尚未确认；重试提示可能产生新外部调用/费用，不默认自动执行。过期按钮返回409后刷新状态并解释，不将请求失败显示成取消成功。

### F05 搜索 `/search?q=...`

输入与筛选在上方，左侧结果，右侧可选预览。默认统一搜索体验；诊断详情可展示关键词/混合模式，不能要求普通用户理解RRF后才能搜索。输入300ms debounce、Abort旧请求、响应关联queryKey；旧请求晚返回不能覆盖新查询。URL保存q/filter/sort；游标由后端返回，不伪造offset。

结果包含标题、2–3行匹配片段、来源、标签、引用版本；query高亮使用安全文本节点，不拼原始HTML。向量不可用时提示“语义检索暂不可用，已显示关键词结果”；partial显示“部分结果暂不可用”及刷新操作。结果进入F03固定revision。无结果有去掉筛选建议，禁止自动调用模型编造库内答案。

### F06 Agent 工作台 `/agent`、`/agent/sessions/:sessionId`

桌面左侧会话列表240px，中心对话max800px，右侧运行详情按需展开320px；1280以下详情drawer，手机会话drawer。空态提供3个真实可执行任务示例：“比较选中文章观点 / 依据资料生成复习卡 / 整理本次学习笔记”。示例按钮只填输入，不自动开始收费模型调用。

输入区必须显示选定资料scope、记忆开关、预算入口；发送后显示run及停止入口。消息流显示回答与引用；工具调用折叠卡展示工具名、人类可理解动作、RUNNING/SUCCEEDED/FAILED、耗时和可公开结果，不能展示模型隐藏思维或完整秘密参数。大结果为受控artifact链接；只读并发工具以调用卡呈现，不要求用户理解线程。

运行中用户滚动查看旧消息不强制跳底，显示“有新内容”按钮。断线不丢消息；snapshot与eventId重放合并。WAITING_APPROVAL/NEEDS_DECISION显示置顶行动卡；预算不足、压缩中、取消中、失败各有独立状态。新建会话不继承旧会话隐含scope，恢复会话遵循服务器授权。

### F07 审批 Drawer / `/approvals/:approvalId`

宽720px/max96vw；固定标题“确认修改”、操作对象、原因摘要、逐字段before/after diff、影响数量、过期时间、当前资源版本。底部“拒绝”和“批准本次修改”；批准前checkbox明确范围（单纯只读操作不出现审批）。不得显示“一律允许所有后续操作”。

批准请求只携带绑定proposal身份/版本的契约字段，参数变化必须重新提议。提交中不可双击；响应未确认先查action结果，不新建action重试。409显示“内容已变化，请重新生成提议”，过期显示“提议已过期”；已执行展示结果与回链，不再次执行。用户关闭Drawer不等于拒绝，也不等于批准。

### F08 记忆管理 `/settings/memory`

列表字段：明确内容摘要、scope、来源（用户确认/替代）、更新时间、状态；状态Tab有效/已替代/已撤销。新记忆编辑先预览，再明确保存；模型推测不得自动加入有效列表。编辑通过新版本替代，撤销显示影响与边界“后续新授权调用不再使用；已经授权的请求可能仍在处理中”。不能用“已彻底忘记所有请求”夸大效果。

提供删除/撤销入口时语义以04为准，墓碑/审计在服务端保留；UI不假装物理清除。旧搜索候选和跨会话cache刷新后不能显示已失效记忆为有效。记忆正文不发前端分析埋点。

### F09 卡片库 `/cards` 与编辑器

Tab四类型：问答/挖空/背诵/时间戳；列表可按到期/暂停/leech/标签筛选。编辑器宽800px，左编辑右预览（手机上下）；每型字段与schema一致。问答必须问题+答案；挖空必须有效cloze标记且能预览；背诵显示段落及提示；时间戳显示来源与时间区间，不能播放未取得的音视频。

来源引用显示原条目/版本/片段；失效来源保留卡片并标“来源暂不可定位”，不删用户编辑。AI生成是草稿，可逐卡编辑/选择保存，不能批量无审批写入。保存失败保留草稿；卡片version冲突提供刷新后对比，不能静默覆盖。

### F10 复习 `/review`

中心卡max800px，顶部进度与退出，内容占主体，底部操作固定但不遮正文。未揭示答案只有“显示答案”，揭示后显示四按钮“重来 / 困难 / 良好 / 轻松”，对应q0/3/4/5；下一次间隔由服务端预览而非前端另算。键盘Space揭示、1–4评分（仅当前无输入焦点/无弹层/非输入法组合态）。

评分requestId稳定、stateVersion校验；pending不切下一张，成功后才推进；网络未确认先查原请求，409刷新状态并提示。无到期卡显示完成页和“查看卡片库”，不是error。离线明确“无法提交评分”，本版不偷偷做离线评分队列。AI关闭仍能复习全部手动卡。

**翻卡为必需交互**：问答和挖空卡以正反面展示；点击“显示答案”或Space触发280ms水平翻转，perspective1200px、transform-style:preserve-3d、两面backface-visibility:hidden。前面显示问题/挖空，背面显示答案+引用；背面不沿用反向文字。状态明确question→flipping→answer→submitting，不在翻转中接受重复翻转或评分。答案揭示后可“再看题目”，该操作不提交评分、不重置已经揭示的事实。

较长背诵卡与时间戳卡采用160ms以内的展开揭示，长文本不强制三维翻转。减少动画模式直接切面、关闭旋转，仍保持相同语义。卡高依据正反内容测量，min280px，长答案允许自然伸展而不裁切；页面底部评分栏不能遮住内容。隐藏面使用aria-hidden/inert或等价焦点管理，不让读屏同时读问题和答案；切面后答案区可感知但不无条件打断用户。反馈/评分按钮在答案已揭示后可用，未收到服务器成功前保持当前卡。完整交互示范见本地reference-board的翻卡区，其数据仅为设计示例。

### F11 设置 `/settings/:section`

二级导航“通用 / AI与预算 / 记忆 / 存储与诊断 / 备份”。每组独立保存和错误，dirty离开提示；不要每个开关一改就写服务器而无反馈。秘密字段只显示已配置/未配置与重新设置入口，API不回传明文；不要在localStorage持久化provider key。

AI状态与预算有单位、周期、当前预留/已记录/未知使用量区别；测试连接明确可能产生调用，并受既有配置预算约束。诊断默认人类描述，技术详情折叠。全局主题light/dark/system，状态共享tokens，不让不同页面各自维护主题。

### F12 备份与恢复 `/settings/backups`

左侧备份列表：时间、范围、大小、完整性、下载；右侧/下一步恢复向导：选择包→只读验证→展示缺对象/版本不兼容→指定新实例/目录→恢复→验证报告。恢复操作在管理权限与明确确认下进行；当前用户实例不被静默覆盖。导出资料和完整备份用不同名称解释。

进度只展示实际步骤/字节，失败保留原实例和恢复日志。浏览器不接受任意服务器路径输入直接执行；目标由服务端受控配置/候选选择。危险操作文案写具体目标与影响，不用模糊“确定吗”。

### F13 回收站 `/trash`

条目显示标题、删除时间、原集合、可恢复状态。首版支持恢复，永久清除单独权限/显式流程；不默认定时清除。恢复后若索引未就绪显示可阅读但搜索处理中，不能假装立即全部恢复。选择多项恢复报告逐项结果，部分失败保留失败项。

### F14 登录与首次初始化 `/login`、`/setup`

卡片宽400px居中，品牌/表单/错误/提交清晰；无营销分屏。首次初始化是否开放由服务端确定，已经初始化不能通过前端路由再创建管理员。密码可见切换有可访问名称，自动完成使用标准属性；错误不泄露账号是否存在。登录后回到合法站内returnTo，防开放重定向。

### F15 集合与标签 `/collections/:id`、`/tags/:id`

复用F01列表/筛选组件，顶部展示名称、说明、编辑；不复制资料库全部逻辑。创建/重命名/归档以契约校验，空集合有添加内容入口。条目和集合/标签关系必须遵循本项目模型，不从参考站点自行推断单集合或多集合规则。关联变更使相关列表和count缓存失效；并发版本冲突显式提示。

## 5. 跨页面状态和文案

每页必须区分loading、empty、error、unauthorized；异步页增加pending、stale、partial，写页增加conflict。不存在的情况在页面合同写N/A原因，不能缺省不做。成功toast只在服务端确认后展示；关键失败使用持久inline banner，不能3秒后消失。错误显示可行动描述和可复制requestId，堆栈不直接给用户。

网络离线与AI关闭是两个不同维度。AI关闭只禁用模型功能，保存/阅读/关键词/手动学习照常；网络离线只显示已加载信息并禁止需要服务器确认的写入，不承诺PWA离线产品。旧版“离线学习”相关表述按此解释为“不调用外部AI仍可学习”，不是浏览器脱网后照常写服务器。

## 6. 不做什么

不让Agent凭审美重画导航，不复制外站业务边界，不把静态稿当真实应用，不给未实现API填随机样本假装成功，不以视觉统一为由隐藏UNKNOWN/审批冲突/记忆撤销边界，不承诺原生手机或完整离线同步。
